# KOC 数据记录工具

记录抖音和小红书作品的点赞数、评论数、收藏数、转发数，支持作品链接、标题、作者、备注、搜索、平台筛选、编辑、删除和 CSV 导出。

这是手动录入版本：打开原作品查看数量，再填写到工具中。未知的数据请留空，零表示确实为零。不会自动读取平台数据。

## 启动

需要 Python 3.10 或更新版本，无需安装额外依赖。在项目文件夹执行：

```bash
python app.py
```

在自己的电脑浏览器中打开 `http://127.0.0.1:8000`。保持终端开启；按 Ctrl+C 停止。云环境中的服务需要通过所在平台提供的访问方式打开，本仓库不包含公网部署。

数据自动保存到 `.data/records.sqlite3`，重启后保留。停止程序后可复制整个 `.data` 文件夹备份，或点击“导出全部 CSV”备份表格。CSV 可用 Excel 打开。导出时间为 UTC，页面按浏览器时区显示。

可选参数：`--port 8001`、`--db /path/to/records.sqlite3`。默认只监听本机；此版本不含账号权限功能，适合个人使用。

## 验证

```bash
python -m unittest discover -s tests -v
node --check static/app.js
```

测试使用临时数据库，不会修改真实记录，覆盖新增、编辑、删除、重启持久化、输入校验、未知数量与零值、CSV 导出及页面资源。
